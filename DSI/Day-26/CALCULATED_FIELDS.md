# Calculated Fields Reference — OmniCorp Dashboard LOD Expressions

This document provides the complete Tableau calculated field definitions for the OmniCorp Retail Dashboard. Each field is categorized by its LOD type and includes documentation for easy reference.

---

## 📁 LOD — Global Level

### 1. Grand Total Sales

```tableau
// Returns the sum of sales across ALL data, ignoring all view dimensions & filters
// Type: Bare LOD (no keyword = FIXED-like behavior)
// Use: Denominator for % of Total calculations
{ SUM([Sales]) }
```

### 2. Overall Avg Sales Benchmark

```tableau
// Returns the average sales across all time periods
// When placed on a monthly trend chart, this shows as a flat benchmark line
// Type: EXCLUDE (removes date dimensions from calculation)
{ EXCLUDE [Order Date] : AVG([Sales]) }
```

### 3. Overall Profit Margin

```tableau
// Returns the profit margin (Profit/Sales) across the entire business
// Type: Bare LOD
{ SUM([Profit]) / SUM([Sales]) }
```

---

## 📁 LOD — Customer Level (FIXED)

### 4. Total Sales Per Customer

```tableau
// Sums all sales for each customer, regardless of view dimensions
// Type: FIXED on Customer ID
// Use: Customer-level analysis, ranking customers
{ FIXED [Customer ID] : SUM([Sales]) }
```

### 5. Avg Order Value Per Customer

```tableau
// Average sale amount per order for each customer
// Type: FIXED on Customer ID
// Use: Understanding customer spending habits
{ FIXED [Customer ID] : AVG([Sales]) }
```

### 6. Total Orders Per Customer

```tableau
// Counts distinct orders placed by each customer
// Type: FIXED on Customer ID
// Use: Frequency analysis, loyalty segmentation
{ FIXED [Customer ID] : COUNTD([Order ID]) }
```

### 7. First Purchase Date

```tableau
// Earliest order date for each customer
// Type: FIXED on Customer ID
// Use: Cohort analysis, customer tenure
{ FIXED [Customer ID] : MIN([Order Date]) }
```

### 8. Last Purchase Date

```tableau
// Most recent order date for each customer
// Type: FIXED on Customer ID
// Use: Recency analysis, churn prediction
{ FIXED [Customer ID] : MAX([Order Date]) }
```

### 9. Customer Tenure (Days)

```tableau
// Number of days between first and last purchase
// Type: FIXED on Customer ID (nested inside DATEDIFF)
// Use: Loyalty measurement
DATEDIFF('day',
  { FIXED [Customer ID] : MIN([Order Date]) },
  { FIXED [Customer ID] : MAX([Order Date]) }
)
```

### 10. Customer Lifetime Value (CLV)

```tableau
// Total profit generated by each customer
// Type: FIXED on Customer ID
// Use: High-value customer identification
{ FIXED [Customer ID] : SUM([Profit]) }
```

### 11. Is High Value Customer

```tableau
// Flags customers whose total sales exceed $5,000
// Returns TRUE/FALSE — usable as a filter or color
// Type: FIXED on Customer ID (nested conditional)
{ FIXED [Customer ID] : SUM([Sales]) } > 5000
```

### 12. Customer Recency Score

```tableau
// Days since customer's last purchase (from today)
// Lower = more recent = more engaged
// Type: FIXED on Customer ID
DATEDIFF('day',
  { FIXED [Customer ID] : MAX([Order Date]) },
  TODAY()
)
```

### 13. Repeat Customer Flag

```tableau
// TRUE if customer has placed more than 1 order
// Type: FIXED on Customer ID
{ FIXED [Customer ID] : COUNTD([Order ID]) } > 1
```

### 14. Customer Order Frequency

```tableau
// Average number of days between orders for each customer
// Type: FIXED on Customer ID (combination of two LODs)
{ FIXED [Customer ID] : DATEDIFF('day', MIN([Order Date]), MAX([Order Date])) } /
  NULLIF({ FIXED [Customer ID] : COUNTD([Order ID]) - 1 }, 0)
```

## 📁 LOD — Category Level (FIXED)

### 15. Total Sales Per Category

```tableau
// Sum of sales grouped by Category only, ignoring other view dimensions
// Type: FIXED on Category
// Use: Denominator for % of Category calculations
{ FIXED [Category] : SUM([Sales]) }
```

### 16. % of Category Total

```tableau
// Each Sub-Category's sales as a percentage of its parent Category's sales
// Type: FIXED on Category (denominator)
SUM([Sales]) / { FIXED [Category] : SUM([Sales]) }
```

### 17. Monthly Target by Category

```tableau
// Monthly sales target per category, fixed at Category + Month level
// Type: FIXED on Category and Month
// Use: Target comparison in bullet charts
{ FIXED [Category], DATETRUNC('month', [Order Date]) : SUM([Sales Target]) }
```

### 18. Target Achievement %

```tableau
// Actual sales divided by target, as a percentage
// Type: FIXED LOD in denominator
// Use: Performance against goals
SUM([Sales]) / { FIXED [Category], DATETRUNC('month', [Order Date]) : SUM([Sales Target]) }
```

### 19. Category Avg Profit Margin

```tableau
// Average profit margin for each category (Profit/Sales at category level)
// Type: FIXED on Category
// Use: Comparing sub-category performance to category average
{ FIXED [Category] : SUM([Profit]) / SUM([Sales]) }
```

### 20. Performance vs Category Avg

```tableau
// Difference between a sub-category's profit margin and its category average
// Positive = over-performing, Negative = under-performing
// Type: FIXED on Category (denominator)
(SUM([Profit]) / SUM([Sales])) - { FIXED [Category] : SUM([Profit]) / SUM([Sales]) }
```

### 21. Category Sales Rank

```tableau
// Ranks categories by total sales (1 = highest)
// Type: FIXED on Category
// Use: Identifying top/bottom categories
RANK({ FIXED [Category] : SUM([Sales]) })
```

## 📁 LOD — Region Level (FIXED & EXCLUDE)

### 22. Total Sales Per Region

```tableau
// Sum of sales grouped by Region, ignoring other view dimensions
// Type: FIXED on Region
{ FIXED [Region] : SUM([Sales]) }
```

### 23. Region Profit Share %

```tableau
// Each store's profit as a percentage of its region's total profit
// EXCLUDE removes Store and Category, keeping Region
// Type: EXCLUDE
SUM([Profit]) / { EXCLUDE [Store Name], [Category] : SUM([Profit]) }
```

### 24. Store vs Region Avg Profit

```tableau
// Difference between a store's profit and the regional average
// EXCLUDE removes Store Name to compute regional baseline
// Type: EXCLUDE
SUM([Profit]) - { EXCLUDE [Store Name] : AVG([Profit]) }
```

### 25. Region Level Avg Sales

```tableau
// Average sales at the Region level (across all stores in that region)
// Type: FIXED on Region
{ FIXED [Region] : AVG([Sales]) }
```

### 26. Store Performance Index

```tableau
// Individual store sales vs. region average (1.0 = at average, >1.0 = above)
// Type: EXCLUDE on Store Name (denominator)
SUM([Sales]) / { EXCLUDE [Store Name] : AVG([Sales]) }
```

## 📁 LOD — Channel Level (FIXED)

### 27. Total Spend Per Channel

```tableau
// Sum of marketing spend for each channel
// Type: FIXED on Channel
// Use: CAC calculation denominator
{ FIXED [Channel] : SUM([Spend]) }
```

### 28. New Customers Per Channel

```tableau
// Count of distinct customers acquired through each channel
// Type: FIXED on Channel
// Use: CAC calculation denominator
{ FIXED [Channel] : COUNTD([Customer ID]) }
```

### 29. Customer Acquisition Cost (CAC)

```tableau
// Cost to acquire a single customer through each channel
// Type: FIXED on Channel (two LODs divided)
{ FIXED [Channel] : SUM([Spend]) } / { FIXED [Channel] : COUNTD([Customer ID]) }
```

### 30. Channel Conversion Rate

```tableau
// Percentage of clicks that result in conversions
// Type: FIXED on Channel
{ FIXED [Channel] : SUM([Conversions]) } / { FIXED [Channel] : SUM([Clicks]) }
```

## 📁 LOD — INCLUDE Expressions

### 31. Avg Sales Per Customer (by Region)

```tableau
// At Region granularity in the view, this computes the average per customer
// Then aggregates back to Region level
// Type: INCLUDE on Customer ID
// Without this, AVG([Sales]) averages individual transactions, not customers
{ INCLUDE [Customer ID] : AVG([Sales]) }
```

### 32. Products Per Order

```tableau
// Counts distinct products in each order, then aggregates to view level
// Type: INCLUDE on Order ID
// Use: Basket size analysis
{ INCLUDE [Order ID] : COUNTD([Product ID]) }
```

### 33. Avg Basket Size (by Category)

```tableau
// Average number of products per order, grouped by Category view level
// Type: INCLUDE on Order ID
{ INCLUDE [Order ID] : COUNTD([Product ID]) }
```

### 34. Orders Per Store Day

```tableau
// Number of distinct orders placed per store per day
// Type: INCLUDE on Store ID and Order Date
{ INCLUDE [Store ID], [Order Date] : COUNTD([Order ID]) }
```

## 📁 Parameter-Driven LOD Calculations

### 35. Dynamic Sales Benchmark

```tableau
// Changes the benchmark based on a parameter selection
// Supports: Overall Avg, Category Avg, Region Avg
// Type: Combination using CASE + LODs
CASE [Sales Benchmark Type]
  WHEN "Overall Avg" THEN { AVG([Sales]) }
  WHEN "Category Avg" THEN { FIXED [Category] : AVG([Sales]) }
  WHEN "Region Avg" THEN { FIXED [Region] : AVG([Sales]) }
END
```

### 36. Top N Customers Filter

```tableau
// Filters to show only the top N customers by sales
// Used as a boolean filter on the Customers sheet
// Type: FIXED on Customer ID
RANK({ FIXED [Customer ID] : SUM([Sales]) }) <= [Top N Customers]
  OR [Top N Customers] = 999  // 999 = "All"
```

## 📁 Utility Calculations (Non-LOD Helpers)

### 37. Discount Band

```tableau
// Categorizes discounts for analysis
IF [Discount] = 0 THEN "No Discount"
ELSEIF [Discount] <= 0.20 THEN "Low Discount"
ELSEIF [Discount] <= 0.50 THEN "Medium Discount"
ELSE "High Discount"
END
```

### 38. Order Year-Month

```tableau
// Formatted year-month string for chronological analysis
DATENAME('year', [Order Date]) + '-' + DATENAME('month', [Order Date])
```

### 39. isActiveCustomer

```tableau
// True if customer purchased within the last 90 days
{ FIXED [Customer ID] : MAX([Order Date]) } >= DATEADD('day', -90, TODAY())
```

### 40. Customer Segment Rank

```tableau
// Rank customers by total sales within their segment
RANK({ FIXED [Customer ID] : SUM([Sales]) })
```

## Quick Reference: LOD Type by Use Case

| Use Case                                   | LOD Type                      | Example                                                            |
| ------------------------------------------ | ----------------------------- | ------------------------------------------------------------------ |
| "Show me the grand total"                  | **Bare**                      | `{ SUM([Sales]) }`                                                 |
| "Show me per-customer metrics"             | **FIXED [Customer ID]**       | `{ FIXED [Customer ID] : SUM([Sales]) }`                           |
| "Show me monthly targets by category"      | **FIXED [Category], [Month]** | `{ FIXED [Category], DATETRUNC('month', [Date]) : SUM([Target]) }` |
| "Compare stores to region baseline"        | **EXCLUDE [Store Name]**      | `SUM([Profit]) - { EXCLUDE [Store Name] : AVG([Profit]) }`         |
| "Compute avg per customer at region level" | **INCLUDE [Customer ID]**     | `{ INCLUDE [Customer ID] : AVG([Sales]) }`                         |
| "Compute products per order at any level"  | **INCLUDE [Order ID]**        | `{ INCLUDE [Order ID] : COUNTD([Product ID]) }`                    |
| "Show % of total ignoring filters"         | **FIXED (no dims)**           | `SUM([Sales]) / { SUM([Sales]) }`                                  |
| "Dynamic benchmark switching"              | **CASE + Multiple LODs**      | See #35 above                                                      |

## Implementation Notes

### Performance Tips

1. **FIXED LODs are fastest** — They compute once per group and cache the result
2. **INCLUDE on high-cardinality** — Be careful with INCLUDE on Customer ID (100k+) or Order ID (millions+)
3. **EXCLUDE is efficient** — It's usually just subtracting from the view level
4. **Use extracts** — LODs push SQL to the database; extracts reduce query time

### Order of Operations in Tableau

1. Context Filters → 2. Data Source Filters → 3. **LOD Expressions** → 4. Dimension Filters → 5. Measure Filters → 6. Table Calculations

> ⚠️ **Important:** FIXED LODs compute BEFORE dimension filters. If you need FIXED to respect a filter, promote it to Context Filter.

### Naming Convention

- Prefix LOD fields with the LOD type for easy identification: `[FIXED] Total Sales Per Customer`
- Or group them in folders (as shown in the dashboard design)
