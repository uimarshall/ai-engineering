KEY INSIGHTS DOCUMENTED
================================================================================

1. K SELECTION IS NOT ONE-SIZE-FITS-ALL
   Different datasets have different optimal K values.
   Must test systematically to find what works.

2. HEURISTIC IS A STARTING POINT
   K = sqrt(n_samples) is good first guess, but always verify
   by testing nearby odd values (K-2, K, K+2).

3. CROSS-VALIDATION > TRAIN/TEST
   Train/test split can be unlucky.
   5-fold cross-validation more robust and reproducible.

4. ALWAYS USE ODD NUMBERS
   Even K with even number of classes creates ties.
   Odd numbers guarantee clear winner in voting.

5. SCALING IS CRITICAL
   Without scaling, large-range features dominate.
   Normalization (0-1) recommended for KNN specifically.

6. EVALUATE ON TEST DATA ONLY
   Training data evaluation leads to overfitting.
   Always use test/validation set or cross-validation.

7. IMBALANCE REQUIRES SPECIAL HANDLING
   Large K can drown out minority classes.
   Use K=3-5 when classes imbalanced.

8. SMALL DATASETS ARE CHALLENGING
   K < n_training_samples / 2 is guideline.
   Cross-validation more important than train/test split.
